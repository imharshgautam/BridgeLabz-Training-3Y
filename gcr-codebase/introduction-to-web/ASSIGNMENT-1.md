## ASSIGNMENT 1

## 1. Explain the difference between frontend, backend, and full- stack development with suitable real-world examples.

Frontend = what the user sees and interacts with (buttons, layout, colors, animations).

Ex: Making a "Buy Now" button look good and clickable on Amazon.

Backend = the logic and data handling that runs behind the scenes (server, database, business logic).

Ex: students' data is recorded in the college server.

Full-stack = it is the combination of frontend and backend both.

Ex: A dev who builds the whole Amazon checkout flow — UI +

payment logic + database — solo.

## 2. Create a simple diagram showing how the client-server model works in web architecture.

Client: Sends a request (e.g. opens a website, clicks a button) Server: Receives the request, processes it, sends back data Client: Displays the response to the user.
